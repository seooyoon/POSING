# 02 화면 배치와 동작

기준: 서윤의 iPhone 16 Pro 기본 카메라 스크린샷 (iOS 26, 2026-10-23). 스크린샷은 `docs/reference/` 폴더에 넣어 둔다. 아래 설명과 스크린샷이 다르면 **스크린샷이 기준**이다.

## 1. 전체 구조 (사진 모드, 세로)

```
┌──────────────────────────────────────┐
│ [JPEG 24] (초기화)(포즈)(MY) [⚡ ◎ •••] │  ← 상단 바
│ ┌──────────────────────────────────┐ │
│ │ (포즈 패널 또는 MY 패널 — 하나만)  │ │  ← 목록 + 투명도 조절 바, 미리보기 위에 겹침
│ │                                  │ │
│ │      카메라 미리보기 (4:3)         │ │
│ │   + MY 사진 레이어 (반투명)         │ │
│ │   + 포즈 테두리 레이어              │ │
│ │   + 3x3 격자 / 초점 사각형          │ │
│ │                                  │ │
│ │ (꽃)        .5  [1×]  2   5       │ │  ← 배율 버튼 (미리보기 하단 안쪽)
│ └──────────────────────────────────┘ │
│  [카메라]         ( ◯ )                │  ← 카메라 버튼(셔터 왼쪽) · 셔터
│   (썸네일)   [비디오 | 사진]   (전환)    │  ← 하단 줄
└──────────────────────────────────────┘
```

## 2. 상단 바

- 높이·여백은 기본 카메라와 동일. 버튼 판은 반투명 어두운 캡슐 (`.ultraThinMaterial` 계열 + 어두운 색)
- 왼쪽 ①: 형식 버튼 캡슐 `JPEG 24` (비디오 모드에서는 `4K 해상도 30 FPS`). 탭·꾹 누르기 → 빠른 설정 판. 비디오: `해상도 | HD · 4K`, `프레임률 | 24 · 30 · 60` (기본값 4K · 30). 사진: (`포맷 | JPEG · RAW`, `해상도 | 24 · 48 MP` (RAW는 12 · 48), 선택값은 노란 글자, 기본값 앞에 점 (색은 글자를 따라감), 아래에 "최대 NMP의 해상도입니다.")
- 왼쪽 ②: **새로 추가하는 버튼 3개** — `초기화`, `포즈`, `MY`
  - 하나로 묶인 캡슐이 아니라 **각각 따로 떨어진 둥근 버튼 3개** (버튼 사이 간격 8pt)
  - 각 버튼은 형식 버튼(`JPEG 24`)과 같은 높이·배경·글자 크기, 폭은 글자에 맞춤
  - 열려 있는 패널의 버튼(포즈 또는 MY)은 노란색
  - 포즈가 선택되어 있으면 포즈 글자 아래 작은 점, MY 사진이 선택되어 있으면 MY 글자 아래 작은 점
  - 꾹 누르기가 인식되면 버튼이 살짝 커졌다 돌아오는 애니메이션 (햅틱 없음. 초기화, MY만. 포즈는 반응 없음)
- 오른쪽: 캡슐 `플래시 · LIVE · •••` (기본 카메라의 야간 모드 아이콘 없음). 아이콘마다 터치 범위를 넉넉하게. 꾹 누르기 → 빠른 설정 판 (`플래시 | 자동 · 켬 · 끔`, `LIVE | 켬 · 끔`)
- 빠른 설정 판: 누른 버튼 자리(형식 = 왼쪽 위, 오른쪽 묶음 = 오른쪽 위)에서 흐릿하게 부풀어 나오는 반투명 둥근 판, 닫을 때는 그 자리로 되돌아감 (열린 동안 상단 바는 숨김, 판 위쪽 = 버튼 위쪽, 좌우 여백 8.5pt). 값은 칸마다 글자 시작이 같고, LIVE 켬 · 끔은 플래시 켬 · 끔과 같은 칸. 기본값 점은 글자 왼쪽 바깥. 판 바깥을 탭하면 닫힘
- LIVE를 켜고 끄면 미리보기 위쪽 가운데에 잠깐 표시: 켬 = 노란 판 `LIVE`, 끔 = 흰 판 `LIVE 끔` (글자는 어둡게). LIVE 사진을 찍는 순간에도 `LIVE`
- "자동 노출/초점 고정" 표시는 미리보기가 상단 바 뒤까지 올라가도(비디오 · 16:9) 상단 바 아래에 둠
- 폭이 부족하면 형식 버튼을 줄이지 말고 서윤에게 배치를 묻는다

## 3. 포즈 · MY 패널

- 상단 바 바로 아래, 미리보기 위에 겹쳐서 표시. 반투명 어두운 배경 띠 하나 안에 두 줄:
  - 1줄: 가로 목록 — 정사각형 썸네일 약 56pt, 둥근 모서리 8pt, 간격 8pt, **왼쪽 정렬**, 좌우 스크롤
  - 2줄: 투명도 조절 바 — 왼쪽에 현재 값(`100%`, `35%`), 오른쪽으로 가로 눈금 슬라이더 (기본 카메라 노출 눈금 바 느낌). 5% 단위 스냅, 값이 바뀔 때 가벼운 햅틱. 선택된 레이어가 없으면 흐리게
- 선택된 칸: 노란 테두리 2pt
- 포즈 패널과 MY 패널은 같은 자리, 한 번에 하나만. 전환할 때는 내용만 바뀌고 띠는 그대로
- 나타남/사라짐: 위에서 살짝 내려오며 페이드 (0.2초)
- MY 목록이 비어 있으면 목록 자리에 "MY를 꾹 눌러 사진을 추가하세요" 한 줄
- MY 사진 추가는 시스템 사진 피커 사용 (아래에서 올라오는 시트, 선택 번호 표시, 오른쪽 위 **추가** 버튼). 참고 화면: `docs/reference/picker_example.png` (카카오톡 사진 선택 화면 — 이 느낌의 흐름이라는 뜻이고 디자인은 iOS 시스템 피커 그대로)

## 4. 설정 화면

- 초기화 버튼을 꾹 누르면 아래에서 올라오는 전체 화면 시트
- **아이폰 설정 앱 > 카메라 화면과 똑같은 스타일** (`docs/reference/settings_style.png`): SwiftUI `List` + `.insetGrouped`, 섹션 제목·설명(footer)은 시스템 기본, 스위치는 시스템 `Toggle`, 다음 화면은 `NavigationLink` (오른쪽 `›`)
- 카메라 화면과 달리 **시스템 밝은/어두운 모드를 따름**
- 맨 위 카드: 앱 아이콘 (현재 아이콘 + 수정 버튼 → 펼치면 가로 아이콘 목록 + 취소·확인 버튼). 아이콘은 iOS 홈 화면 아이콘처럼 둥근 사각형으로 잘라 표시, 선택된 아이콘은 시스템 파란 테두리 + 체크
- 항목과 하위 화면은 `docs/01_SPEC.md` 6절

## 5. 미리보기 영역

- 4:3일 때 기본 카메라와 같은 위치·크기. 16:9, 1:1일 때는 기본 카메라처럼 영역 모양이 바뀜
- 미리보기 바깥(상단 바 · 하단 영역, 1:1 · 16:9의 남는 자리)은 기본 카메라처럼 장면이 어둡게 비침 (흐림 없음, 어두운 장면이면 거의 검정). 1:1은 4:3 영상의 위아래가 이어서 비치고, 그 밖은 같은 영상을 화면 전체로 키워 깜 (기본 카메라는 더 넓은 렌즈로 채우지만 카메라를 두 개 돌리면 발열이 커서 쓰지 않음). 스타일 화면에서는 검정
- 레이어 순서 (아래 → 위, 항상 고정): 카메라 → MY 사진 → 포즈 테두리 → 격자·중심점 → 초점 사각형·수평계 → 배율 버튼·꽃 버튼
- 초점 사각형: 노란 얇은 사각형, 모서리 중간에 짧은 눈금, 오른쪽에 해 아이콘. 탭 후 약 2초 뒤 흐려짐

## 6. 배율 버튼

- `.5 · 1 · 2 · 5` 가로 배치. 바탕 캡슐 없이 글자만. 어두운 원은 화면 가운데에 고정이고, 현재 버튼이 그 안에 노란 글씨 + `×`로 들어옴 (0.5배는 `0.5×`). 줄 위치는 모드 · 비율과 상관없이 같음
- 버튼을 누르면 중간 숫자 없이 배율이 바로 바뀌고 글자 줄이 밀려 그 버튼이 가운데로 옴
- 1×를 누르면 원 안에 잠깐 `24 MM`이 보였다가 `1×`로 돌아옴. 이미 1× 쪽이면 누를 때마다 24 → 28 → 35mm
- 두 손가락 · 다이얼로 배율이 버튼 값과 달라지면 가장 가까운 버튼 자리에 실제 값 표시 (예: `7×`, `1.4×`)
- 길게 누르거나 좌우로 밀면 다이얼이 펼쳐짐 (0.5×~25×), 손을 떼면 1.5초 뒤 접힘. 카메라 컨트롤로 배율이 바뀔 때도 보임 (두 손가락 확대 · 배율 버튼 탭은 다이얼 없음)
- 다이얼: 셔터 뒤 하단까지 덮는 큰 반투명 원. 가장자리에 촘촘한 눈금(큰 배율 숫자 자리는 길고 밝게), 안쪽에 원을 따라 기운 `0.5 · 1 · 2 · 5 · 25`와 `13MM · 24MM · 120MM`, 28·35mm 자리 점. 맨 위 가운데 노란 삼각형과 노란 현재 배율, 화각 이름이 있는 배율이면 그 아래 노란 mm

## 7. 하단

- 셔터: 흰 원 + 바깥 반투명 회색 링. 찍는 동안(플래시 포함) 누른 셔터는 무시. 어두운 장면이나 렌즈를 가렸을 때는 링 · 모드 캡슐 · 전환 버튼 · 빠른 설정 판이 어두운 모양으로 바뀜. 비디오 계열은 빨간 원, 녹화 중 빨간 둥근 사각형
- **카메라 버튼**: 셔터와 같은 줄, 셔터 왼쪽 (썸네일 바로 위쯤). 약 52pt 정사각형 안에 선택된 카메라 PNG를 그대로 표시 (배경 없음, 투명 PNG 모양 그대로). 버튼 바로 아래에 카메라 이름 (11pt 흰 글자, 버튼과 간격 약 3pt). 누를 때 살짝 작아지는 눌림 효과. 꾹 누르거나 위아래로 밀면 목록이 열리고 손가락을 따라 칸이 바뀜 (칸이 바뀔 때 가벼운 햅틱, 목록이 길면 고른 칸이 보이게 스크롤)
- **카메라 목록**: 카메라 버튼 바로 위로 세로 한 줄, 화면 왼쪽 가장자리 정렬, 아래에서 위로 쌓임 (1번이 맨 아래). 칸 약 52pt, 간격 10pt, 반투명 어두운 둥근 배경 띠. 아래에서 위로 펼쳐지는 애니메이션 (0.2초). 칸이 많아 미리보기 위쪽까지 닿으면 세로 스크롤
- 스타일 화면에서는 카메라 버튼 숨김
- 하단 줄 평상시: 왼쪽 원형 썸네일, 가운데 `비디오 | 사진` 캡슐 (선택 모드와 옆 모드 2개, 타임랩스 · 슬로 모션을 고르면 `타임랩스 | 슬로 모션` · `슬로 모션 | 비디오`), 오른쪽 전환 버튼
- 슬로 모션: 형식 버튼 `HD 해상도 120 FPS`, 판은 `프레임률 | 120 · 240`, 셔터 링에 촘촘한 눈금. 타임랩스: 형식 버튼 없음
- 캡슐: 탭하면 누른 쪽 모드. 누른 채 좌우로 밀거나 꾹 누르면 모드 줄로 펼쳐지고(썸네일·전환 버튼 사라짐), 가운데 강조 판은 그대로인 채 글자 줄이 손가락을 따라 미끄러짐 (판에 가장 가까운 모드 글자만 노란색, 간격은 접힌 캡슐과 같음). 떼면 판에 가장 가까운 모드로 자리 잡음 (반 칸을 못 넘겨도 25pt 이상 밀었으면 민 쪽 모드)
- 모드 줄을 좌우로 밀면: 썸네일·전환 버튼이 사라지고 `타임랩스 · 슬로 모션 · 비디오 · 사진`이 나열되며 선택 모드가 가운데 둥근 판에 노란 글씨 (스크린샷 참고). 양 끝은 페이드
- 썸네일 탭 → 기본 사진 앱 열기

## 8. 더보기 메뉴 (•••)

- 셔터 자리에서 둥근 유리 판이 살짝 튕기며 부풀어 나오고, 닫으면 그 자리로 빠르게 되돌아감 (아래쪽 모서리까지 둥근 판, 좌우 여백 6pt · 아래 8.5pt)
- 열린 동안 상단 바 · 배율 버튼 · 셔터 · 하단 줄은 숨김
- 판보다 어두운 원형 버튼 68pt + 아래 이름. 3열 (가운데끼리 가로 115pt, 세로 132pt)
  - 1줄: 플래시 · LIVE · 타이머
  - 2줄: 노출 · 스타일 · 비율
- 비율 버튼은 아이콘 안에 현재 비율 글자 (`4:3` / `16:9` / `1:1`)
- 판 바깥을 탭하거나 아래로 밀면 닫힘

## 8-1. 스타일 화면

- 더보기 메뉴의 스타일 버튼을 누르면 화면이 스타일 화면으로 바뀜 (참고: `docs/reference/style_*.png`)
- 미리보기가 살짝 줄어든 둥근 카드(모서리 약 24pt)가 되고, 양옆에 이웃 스타일 카드가 조금 보임. 좌우로 밀면 카드가 넘어가며 스타일이 바뀜
- 맨 위 반투명 캡슐에 `톤 · 색상 · 팔레트` 숫자 (굵은 숫자, 부호 포함, 0은 `00`)
- 카드 위쪽 가운데 `색조`/`무드` 캡슐, 아래쪽 스타일 이름 캡슐, 그 아래 페이지 점
- 조절 패드: 약 140pt 정사각형, 11×11 점 격자, 둥근 모서리. 현재 값 위치에 흰 큰 점 + 가로·세로 선의 점이 밝아짐. 가운데 작은 원 = 기본값 위치
- 팔레트 슬라이더: 패드 아래 캡슐 모양, 오른쪽으로 갈수록 스타일 색이 진해지는 그라데이션
- X 버튼: 왼쪽 아래 원형
- 하단 모드 줄·썸네일·전환 버튼은 스타일 화면에서 숨김

## 9. 전면 카메라

- 미리보기 거울 반전. 저장본 반전 여부 설정 (기본: 화면에 보인 그대로)
- 배율 버튼 대신 화각 버튼 (넓게 ↔ 가깝게)
- 플래시 켬 + 어두운 곳: 촬영 순간 화면을 하얗게 밝힘

## 10. 공통

- 카메라 화면은 다크 고정 (설정 화면만 시스템 모드)
- 상태 바 숨김, 세로 고정. 폰을 돌리면 아이콘만 회전 (기본 카메라와 동일)
- 글꼴: 시스템 SF Pro. 선택값 노란색은 기본 카메라 노랑 (`#FFD60A` 근처, 스크린샷과 비교)
