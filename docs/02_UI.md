# 02 화면 배치와 동작

기준: 서윤의 iPhone 16 Pro 기본 카메라 스크린샷 (iOS 26, 2026-10-23). 스크린샷은 `docs/reference/` 폴더에 넣어 둔다. 아래 설명과 스크린샷이 다르면 **스크린샷이 기준**이다.

## 1. 전체 구조 (사진 모드, 세로)

```
┌──────────────────────────────────────┐
│ [JPEG 24] (초기화)(포즈)(MY) [⚡ ◎ •••] │  ← 상단 바
│ ┌──────────────────────────────────┐ │
│ │ (포즈 패널 또는 MY 패널 — 하나만)  │ │  ← 목록 + 투명도 조절 바, 미리보기 위에 겹침
│ │                                  │ │
│ │      카메라 미리보기 (4:3)         │ │
│ │   + MY 사진 레이어 (반투명)         │ │
│ │   + 포즈 테두리 레이어              │ │
│ │   + 3x3 격자 / 초점 사각형          │ │
│ │                                  │ │
│ │ (꽃)        .5  [1×]  2   5       │ │  ← 배율 버튼 (미리보기 하단 안쪽)
│ └──────────────────────────────────┘ │
│  [카메라]         ( ◯ )                │  ← 카메라 버튼(셔터 왼쪽) · 셔터
│   (썸네일)   [비디오 | 사진]   (전환)    │  ← 하단 줄
└──────────────────────────────────────┘
```

## 2. 상단 바

- 높이·여백은 기본 카메라와 동일. 버튼 판은 기본 카메라처럼 효과 없는 반투명 회색 캡슐 (회색 0.22 · 불투명도 0.6, 유리 효과 · 테두리 없음. 분할 토글만 유리 캡슐)
- 왼쪽 ①: 형식 버튼 캡슐 `JPEG 24` (비디오 모드에서는 `4K 해상도 30 FPS`). 탭·꾹 누르기 → 빠른 설정 판. 비디오: `해상도 | HD · 4K`, `프레임률 | 24 · 30 · 60` (기본값 4K · 30). 사진: (`포맷 | JPEG · RAW`, `해상도 | 24 · 48 MP` (RAW는 12 · 48), 선택값은 노란 글자, 기본값 앞에 점 (색은 글자를 따라감), 아래에 "최대 NMP의 해상도입니다.")
- 왼쪽 ②: **새로 추가하는 버튼 3개** — `초기화`, `포즈`, `MY`
  - 하나로 묶인 캡슐이 아니라 **각각 따로 떨어진 둥근 버튼 3개** (버튼 사이 간격 8pt)
  - 각 버튼은 형식 버튼(`JPEG 24`)과 같은 높이·배경·글자 크기, 폭은 글자에 맞춤
  - 열려 있는 패널의 버튼(포즈 또는 MY)은 노란색
  - 포즈가 선택되어 있으면 포즈 글자 아래 작은 점, MY 사진이 선택되어 있으면 MY 글자 아래 작은 점
  - 꾹 누르기가 인식되면 버튼이 살짝 커졌다 돌아오는 애니메이션 (햅틱 없음. 초기화만. 포즈 버튼은 반응 없음. MY 버튼은 커지지 않고 누르고 있는 동안 원본 보기, MY 사진 추가는 패키지 대표 이미지 꾹 누르기)
- 오른쪽: 캡슐 `플래시 · LIVE · •••` (기본 카메라의 야간 모드 아이콘 없음). 아이콘마다 터치 범위를 넉넉하게. 꾹 누르기 → 빠른 설정 판 (`플래시 | 자동 · 켬 · 끔`, `LIVE | 켬 · 끔`)
- 맨 위 줄(상단 바보다 위, 다이내믹 아일랜드 오른쪽): 스타일 아이콘(점 격자). 사진 모드면 표준 스타일에서도 항상 보이고, 표준이 아닌 스타일이면 노란색. 탭 → 스타일 화면 열기 · 닫기 (기본 카메라와 같은 자리)
- 빠른 설정 판: 누른 버튼 자리(형식 = 왼쪽 위, 오른쪽 묶음 = 오른쪽 위)에서 흐릿하게 부풀어 나오는 반투명 둥근 판, 닫을 때는 그 자리로 되돌아감 (열린 동안 상단 바는 숨김, 판 위쪽 = 버튼 위쪽, 좌우 여백 8.5pt). 값은 칸마다 글자 시작이 같고, LIVE 켬 · 끔은 플래시 켬 · 끔과 같은 칸. 기본값 점은 글자 왼쪽 바깥. 판 바깥을 탭하면 닫힘
- LIVE를 켜고 끄면 미리보기 위쪽 가운데에 잠깐 표시: 켬 = 노란 판 `LIVE`, 끔 = 흰 판 `LIVE 끔` (글자는 어둡게). LIVE 사진을 찍는 순간에도 `LIVE`
- "자동 노출/초점 고정" 표시는 미리보기가 상단 바 뒤까지 올라가도(비디오 · 16:9) 상단 바 아래에 둠
- 폭이 부족하면 형식 버튼을 줄이지 말고 서윤에게 배치를 묻는다

## 3. 포즈 · MY 패널

- 상단 바 바로 아래, 미리보기 위에 겹쳐서 표시. 반투명 어두운 배경 띠 하나 안에 두 줄:
  - 1줄: 가로 목록 — 정사각형 썸네일 약 56pt, 둥근 모서리 8pt, 간격 8pt, **왼쪽 정렬**, 좌우 스크롤
  - 2줄: 투명도 조절 바 — 왼쪽에 현재 값(`100%`, `35%`), 오른쪽으로 가로 눈금 슬라이더 (기본 카메라 노출 눈금 바 느낌). 5% 단위 스냅, 값이 바뀔 때 가벼운 햅틱. 선택된 레이어가 없으면 흐리게
- 미리보기를 좌우로 밀어 투명도를 바꾸는 동안: 미리보기 위쪽 가운데(상단 바 아래 12pt)에 반투명 검은 캡슐 "MY **35%**" (이름 흰색, 값 노란색, 14pt, 폰 방향대로 돌아감). 손을 떼면 사라짐
- 선택된 칸: 노란 테두리 2pt
- 포즈 패널과 MY 패널은 같은 자리, 한 번에 하나만. 전환할 때는 내용만 바뀌고 띠는 그대로
- 나타남/사라짐: 위에서 살짝 내려오며 페이드 (0.2초)
- MY 사진 위 가이드: 사람 외곽선 흰 선(약 2pt) + 얼굴 점(눈 · 코 · 입) 흰 점, 둘 다 옅은 검은 그림자로 밝은 배경에서도 보이게 (그림자는 가이드 이미지를 만들 때 미리 그려 넣음. 화면에서 매번 그림자를 계산하면 분할 칸 보기에서 화면이 멈춘 듯 밀림). MY 버튼을 누르고 있는 동안은 가이드 없이 원본 100%
- 폰을 가로로 돌리면 MY 사진 · 가이드도 같이 돌아가 똑바로 보이고 미리보기를 꽉 채움 (아이콘과 같은 방향 · 속도). 포즈 테두리는 그대로
- MY 사진 추가는 패키지 대표 이미지 꾹 누르기 (살짝 커졌다 돌아옴). 추가는 시스템 사진 피커 사용 (아래에서 올라오는 시트, 선택 번호 표시, 오른쪽 위 **추가** 버튼). 참고 화면: `docs/reference/picker_example.png` (카카오톡 사진 선택 화면 — 이 느낌의 흐름이라는 뜻이고 디자인은 iOS 시스템 피커 그대로)

## 4. 설정 화면

- 초기화 버튼을 꾹 누르면 아래에서 올라오는 전체 화면 시트
- **아이폰 설정 앱 > 카메라 화면과 똑같은 스타일** (`docs/reference/settings_style.png`): SwiftUI `List` + `.insetGrouped`, 섹션 제목·설명(footer)은 시스템 기본, 스위치는 시스템 `Toggle`, 다음 화면은 `NavigationLink` (오른쪽 `›`)
- 카메라 화면과 달리 **시스템 밝은/어두운 모드를 따름**
- 맨 위 카드: 앱 아이콘 (현재 아이콘 + 수정 버튼 → 펼치면 가로 아이콘 목록 + 취소·확인 버튼). 아이콘은 iOS 홈 화면 아이콘처럼 둥근 사각형으로 잘라 표시, 선택된 아이콘은 시스템 파란 테두리 + 체크
- 항목과 하위 화면은 `docs/01_SPEC.md` 6절

## 5. 미리보기 영역

- 4:3일 때 기본 카메라와 같은 위치·크기. 16:9, 1:1일 때는 기본 카메라처럼 영역 모양이 바뀜
- 미리보기 바깥(상단 바 · 하단 영역)은 검정. 1:1 · 16:9에서 잘려 나가는 4:3 영상 부분만 미리보기와 같은 크기로 이어서 어둡게 비침 (0.5× · 접사 · 전면 · 비디오 계열 · 스타일 화면은 검정). 기본 카메라처럼 더 넓은 장면으로 바깥을 채우는 것은 트리플 카메라의 초광각 포트도 배율만큼 잘려 나와 불가 → 여행 뒤 메인 · 초광각을 따로 켜는 방식으로 다시 검토 (#97)
- 레이어 순서 (아래 → 위, 항상 고정): 카메라 → MY 사진 → 포즈 테두리 → 격자·중심점 → 초점 사각형·수평계 → 배율 버튼·꽃 버튼
- 초점 사각형: 노란 얇은 사각형, 모서리 중간에 짧은 눈금, 오른쪽에 해 아이콘. 탭 후 약 2초 뒤 흐려짐

## 6. 배율 버튼

- `.5 · 1 · 2 · 5` 가로 배치. 바탕 캡슐 없이 글자만. 어두운 원은 화면 가운데에 고정이고, 현재 버튼이 그 안에 노란 글씨 + `×`로 들어옴 (0.5배는 `0.5×`). 줄 위치는 모드 · 비율과 상관없이 같음
- 버튼을 누르면 중간 숫자 없이 배율이 바로 바뀌고 글자 줄이 밀려 그 버튼이 가운데로 옴
- 지금 배율 원은 어두운 반투명. 분할 중(사진)에는 원 뒤가 검정으로 가려질 수 있어 상단 캡슐과 같은 회색
- 1×를 누르면 원 안에 잠깐 `24 MM`이 보였다가 `1×`로 돌아옴. 이미 1× 쪽이면 누를 때마다 24 → 28 → 35mm
- 두 손가락 · 다이얼로 배율이 버튼 값과 달라지면 가장 가까운 버튼 자리에 실제 값 표시 (예: `7×`, `1.4×`)
- 길게 누르거나 좌우로 밀면 다이얼이 펼쳐짐 (0.5×~25×), 손을 떼면 1.5초 뒤 접힘. 카메라 컨트롤로 배율이 바뀔 때도 보임 (두 손가락 확대 · 배율 버튼 탭은 다이얼 없음)
- 다이얼: 셔터 뒤 하단까지 덮는 큰 반투명 원. 가장자리에 촘촘한 눈금(큰 배율 숫자 자리는 길고 밝게), 안쪽에 원을 따라 기운 `0.5 · 1 · 2 · 5 · 25`와 `13MM · 24MM · 120MM`, 28·35mm 자리 점. 맨 위 가운데 노란 삼각형과 노란 현재 배율, 화각 이름이 있는 배율이면 그 아래 노란 mm

## 7. 하단

- 셔터: 흰 원 + 바깥 반투명 회색 링. 찍는 동안(플래시 포함) 누른 셔터는 무시. 어두운 장면이나 렌즈를 가렸을 때는 링 · 빠른 설정 판이 어두운 모양으로 바뀜. 모드 캡슐 · 전환 버튼은 틴트 없는 유리라 뒤가 검정이면 어둡고 장면이 비치면 그 색이 비침 (기본 카메라와 같음). 비디오 계열은 빨간 원, 녹화 중 빨간 둥근 사각형
- **카메라 버튼**: 셔터와 같은 줄, 셔터 왼쪽 (썸네일 바로 위쯤). 약 52pt 정사각형 안에 선택된 카메라 PNG를 그대로 표시 (배경 없음, 투명 PNG 모양 그대로). 버튼 바로 아래에 카메라 이름 (11pt 흰 글자, 버튼과 간격 약 1pt). 카메라 그림과 이름을 합친 덩어리의 세로 가운데가 셔터 가운데에 오게 약 10pt 올림 (분할 버튼도 이름이 있으면 같은 방식, 로고만 있을 때는 그대로). 누를 때 살짝 작아지는 눌림 효과. 꾹 누르거나 위아래로 밀면 목록이 열리고, 버튼 자리에서 시작해 손가락을 따라 칸이 바뀜 (칸이 바뀔 때 가벼운 햅틱, 목록이 길면 고른 칸이 보이게 스크롤)
- **카메라 목록**: 카메라 버튼 바로 위로 세로 한 줄, 화면 왼쪽 가장자리 정렬, 즐겨찾기 먼저 · 각각 이름순(가나다 → abc)으로 사용자가 보기에 위쪽 · 왼쪽부터 놓임 (세로 · 왼쪽으로 눕힘 = 위에서부터, 오른쪽으로 눕힘 = 아래에서부터). **지금 고른 카메라는 버튼에 있으므로 목록에서 뺌** (다른 카메라가 없으면 목록이 열리지 않음). 칸 약 52pt + 아래 이름(카메라 버튼 이름과 같은 글자), 즐겨찾기면 이미지 오른쪽 위에 작은 분홍 하트(#FA1B58, 약 11pt, 카메라 몸체 오른쪽 위 모서리에 살짝 겹쳐 위에 그림, 배경 없음. 두 번 빠르게 탭해 켜고 끔, 카메라 버튼도 같음), 간격 10pt, 좌우 여백 13pt. 버튼을 밀어 고르는 중이면 그 칸만 불투명하고 나머지는 50%, 아니면 모두 불투명, 반투명 어두운 둥근 배경 띠. 아래에서 위로 펼쳐지는 애니메이션 (0.2초). 칸이 많아 미리보기 위쪽까지 닿으면 세로 스크롤
- 스타일 화면에서는 카메라 버튼 숨김
- **분할 버튼** (`docs/01_SPEC.md` 7-2절): 셔터와 같은 줄, 셔터 오른쪽 (카메라 버튼과 좌우 대칭, 전환 버튼 바로 위쯤). 약 52pt 칸 안에, 기본(1장)이면 상자 · 이름 없이 흰 POSING 로고만(폭 52pt), 분할 중이면 아래 이름(`2분할` 등, 카메라 버튼 이름과 같은 글자). 탭하면 버튼 바로 위로 1 · 2 · 3 · 4 세로 목록 (카메라 목록과 같은 반투명 어두운 둥근 띠, 지금 분할은 노란 그림), 목록 바깥 탭이면 닫힘. 스타일 화면 · 더보기 메뉴에서 숨김
- 분할 중 분할 버튼: 모양 그림 대신 노란 분할 모양 테두리 안에 찍은 칸을 합친 모양 (카메라 버튼의 카메라 그림처럼, 폭 34pt, 사진 비율, 안 찍은 칸은 진한 회색에 번호). 탭 = 분할 목록, 꾹 누르면 화면 전체를 어둡게(검정 85%) 하고 가운데에 합친 모양을 크게 (좌우 여백 24pt, 높이는 화면의 75%까지, 모서리 둥글기 없음, 아무 곳이나 누르면 닫힘). 미리보기 위에는 전체 미리보기 칸을 두지 않음
- 분할 중 미리보기 (사진 모드만): 미리보기 자리를 칸으로 나눠, 지금 칸에는 실시간 화면(저장될 영역이 칸에 꼭 맞게 줄여 옮김, 포즈 레이어 · 격자 · 수평계도 함께. MY 사진은 칸으로 옮기지 않고 미리보기 전체에 그대로, 나머지 칸 위에 겹침), 나머지 칸에는 찍은 사진 또는 진한 회색에 번호. 다른 칸은 눌러도 아무 동작 없음 (다시 찍기는 토글 목록에서만), 지금 칸을 누르면 초점. 테두리 없음. 1:1 · 16:9여도 미리보기 바깥에 4:3 부분이 비치지 않음
- 모두 찍고 다시 찍을 칸도 고르지 않은 상태에서만 셔터 안쪽 원이 노란색 + 검정 `저장` 글자(17pt, 기기 방향대로 돎)로 바뀜. 누르면 저장, 저장 중에는 돌아가는 표시
- 분할 중 미리보기 오른쪽 위 (가장자리에서 10pt, 배율 버튼 줄 위까지만): 토글 캡슐(`찍은 수/칸 수` + 화살표. 열면 ⌃, 닫으면 ⌄. 포즈 · MY 버튼과 같은 글자 크기 · 높이, 바탕은 상단 캡슐과 달리 유리), 토글을 열면 바로 아래에 칸별 사진 목록이 세로로 (토글 가운데 정렬, 칸 비율 그대로, 폭 52pt, 간격 6pt, 배경 없이 사진 + 테두리, 지금 칸은 노란 테두리 1.5pt, 안 찍은 칸은 번호). 칸을 누르면 그 칸을 다시 찍기, 찍은 칸을 꾹 누르면 그 사진만 크게 (분할 버튼 꾹 누르기 크게 보기와 같은 모양)
- 분할 목록(1 · 2 · 3 · 4)이 열려 있는 동안은 이 묶음을 숨김 (겹치지 않게)
- 가로로 돌리면 이 묶음 전체가 돌아감. 보는 사람 기준으로 왼쪽으로 눕히면 왼쪽 위, 오른쪽으로 눕히면 오른쪽 아래에 붙음 (화면 기준으로는 세로 · 좌우 모두 오른쪽 위 모서리) (배율 버튼과 겹치지 않음). 목록은 왼쪽으로 눕히면 토글 아래, 오른쪽으로 눕히면 토글 위로 세로로 펼쳐지고 (화살표는 목록을 접는 쪽), 미리보기 밖으로 나가지 않음 (높이가 모자라면 칸 폭을 줄임). 방향이 바뀌면 묶음이 사라지거나 움직이는 효과 없이 바로 새 방향 · 새 자리로 (돌면서 자리가 흔들리지 않게)
- 카메라 목록 · 분할 목록이 열려 있을 때 목록 바깥 어디든 탭하면 닫힘. 다른 버튼(초기화 · 포즈 · 셔터 등)을 누르면 목록이 닫히면서 그 버튼도 바로 동작 (두 번 누를 필요 없음)
- 하단 줄 평상시: 왼쪽 원형 썸네일, 가운데 `비디오 | 사진` 캡슐 (선택 모드와 옆 모드 2개, 타임랩스 · 슬로 모션을 고르면 `타임랩스 | 슬로 모션` · `슬로 모션 | 비디오`), 오른쪽 전환 버튼
- 슬로 모션: 형식 버튼 `HD 해상도 120 FPS`, 판은 `프레임률 | 120 · 240`, 셔터 링에 촘촘한 눈금. 타임랩스: 형식 버튼 없음
- 모드 글자는 보통 굵기 15.5pt, 고른 모드는 기본 카메라 노랑(Display P3 253 · 246 · 88). 강조 판은 기본 카메라 스크린샷에서 잰 값 그대로: 접힘 = 80×42pt 고른 회색(32/255), 캡슐 끝에서 3.3pt 안쪽 / 펼침 = 83×47pt 위 18 → 아래 39 회색 그라데이션. 둘 다 1pt 가장자리 선(왼쪽 위 · 위 · 오른쪽 아래가 밝고 왼쪽 · 오른쪽 위는 흐림). 펼친 줄에서는 가장자리 선이 글자 위에 얹혀 렌즈처럼 보임
- 캡슐: 탭하면 누른 쪽 모드. 누른 채 좌우로 밀거나 꾹 누르면 모드 줄로 펼쳐지고(썸네일·전환 버튼 사라짐), 가운데 강조 판은 그대로인 채 글자 줄이 손가락을 따라 미끄러짐 (판에 가장 가까운 모드 글자만 노란색, 간격은 접힌 캡슐과 같음). 떼면 판에 가장 가까운 모드로 자리 잡음 (반 칸을 못 넘겨도 25pt 이상 밀었으면 민 쪽 모드)
- 모드 줄을 좌우로 밀면: 썸네일·전환 버튼이 사라지고 `타임랩스 · 슬로 모션 · 비디오 · 사진`이 나열되며 선택 모드가 가운데 둥근 판에 노란 글씨 (스크린샷 참고). 양 끝은 페이드
- 썸네일 탭 → 기본 사진 앱 열기

## 8. 더보기 메뉴 (•••)

- 셔터 자리에서 둥근 유리 판이 살짝 튕기며 부풀어 나오고, 닫으면 그 자리로 빠르게 되돌아감 (아래쪽 모서리까지 둥근 판, 좌우 여백 6pt · 아래 8.5pt)
- 열린 동안 상단 바 · 배율 버튼 · 셔터 · 하단 줄은 숨김
- 판보다 어두운 원형 버튼 68pt + 아래 이름. 3열 (가운데끼리 가로 115pt, 세로 132pt)
  - 1줄: 플래시 · LIVE · 타이머
  - 2줄: 노출 · 스타일 · 비율
- 비율 버튼은 아이콘 안에 현재 비율 글자 (`4:3` / `16:9` / `1:1`)
- 판 바깥을 탭하거나 아래로 밀면 닫힘

## 8-1. 스타일 화면

- 더보기 메뉴의 스타일 버튼을 누르면 화면이 스타일 화면으로 바뀜 (참고: `docs/reference/style_*.png`)
- 미리보기가 살짝 줄어든 둥근 카드(모서리 약 24pt)가 되고, 양옆에 이웃 스타일 카드가 조금 보임. 좌우로 밀면 카드가 넘어가며 스타일이 바뀜. 처음 · 마지막에서는 멈춤 (기본 카메라와 같음)
- 맨 위 반투명 캡슐에 `톤 · 색상 · 팔레트` 숫자 (굵은 숫자, 부호 포함, 0은 `00`)
- 카드 위쪽 가운데 `색조`/`무드` 캡슐, 아래쪽 스타일 이름 캡슐, 그 아래 페이지 점 (기본 카메라처럼 5개만 보이고 고른 점이 창 끝에 닿으면 창이 따라 움직임. 그 너머에 더 있으면 끝 점이 작음)
- 조절 패드: 약 140pt 정사각형, 11×11 점 격자, 둥근 모서리. 현재 값 위치에 흰 큰 점 + 가로·세로 선의 점이 밝아짐. 가운데 작은 원 = 기본값 위치
- 팔레트 슬라이더: 패드 아래 캡슐 모양, 오른쪽으로 갈수록 스타일 색이 진해지는 그라데이션
- X 버튼: 왼쪽 아래 원형
- 스타일 초기화 버튼(포징 추가): 패드 오른쪽, X와 대칭인 원형 `↺`. 누르면 표준 스타일 · 모든 스타일 값 기본값으로. 기본 카메라처럼 값을 바꿔야 서서히 나타나고(약 0.2초), 누르면 커지며 밝아진 뒤 화살표가 시계 반대로 약 200도 돌면서 서서히 사라짐(약 0.45초). 패드 점은 기본 자리로 미끄러지듯 돌아감. 상단 바의 초기화(레이어 해제)와는 다른 버튼
- 1:1: 정사각형 미리보기를 화면 폭 그대로 두고 좌우만 카드 폭으로 자름. 카드는 4:3보다 약 51pt 아래, 셔터는 카드 바로 아래(카드 밖), 패드는 셔터 아래, 스타일 이름 · 점은 카드 아래쪽 안 (기본 카메라 1:1 화면 기준)
- 하단 모드 줄·썸네일·전환 버튼은 스타일 화면에서 숨김

## 9. 전면 카메라

- 미리보기 거울 반전. 저장본 반전 여부 설정 (기본: 화면에 보인 그대로)
- 배율 버튼 대신 화각 버튼 (넓게 ↔ 가깝게)
- 플래시 켬 + 어두운 곳: 촬영 순간 화면을 하얗게 밝힘

## 10. 공통

- 카메라 화면은 다크 고정 (설정 화면만 시스템 모드)
- 상태 바 숨김, 세로 고정. 폰을 돌리면 아이콘만 회전 (기본 카메라와 동일)
  - 화면 회전 잠금과 상관없이 CoreMotion 중력으로 방향을 읽음. 60도 넘게 돌리면 가로, 30도 안으로 돌아오면 세로 (거꾸로 든 경우는 그대로). 0.3초 동안 돎
  - 도는 것: 상단 플래시 · LIVE · ••• 아이콘, 맨 위 스타일 아이콘, 배율 숫자, 접사 · 전면 화각 버튼, 썸네일 사진, 전환 버튼, 카메라 버튼 · 카메라 목록 (이미지와 아래 이름을 한 덩어리로)
- 글꼴: 시스템 SF Pro. 선택값 노란색은 기본 카메라 노랑 (`#FFD60A` 근처, 스크린샷과 비교)
