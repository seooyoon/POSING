# 01 기능 명세

## 1. 핵심 원칙

- 아이폰 기본 카메라(iOS 26, iPhone 16 Pro)와 최대한 똑같은 디자인·동작·기능
- 기본 카메라에 **초기화 · 포즈 · MY** 버튼 3개만 추가
- 레이어는 포즈 테두리 **최대 1개** + MY 사진 **최대 1개**, 합쳐서 **최대 2개**까지 동시에 보임
- 겹치는 순서는 항상 **포즈 테두리가 위, MY 사진이 아래** (선택한 순서와 상관없음)
- 레이어는 화면에만 보이고 저장되는 사진·영상에는 없음
- **모든 기능·동작이 완전 오프라인에서 가능** (촬영, 저장, 포즈·MY, 설정, 사진 추가 모두)
- 찍은 사진·영상은 **아이폰 기본 사진 앱에 자동 저장**. 앱 자체 갤러리 없음
- 홈 화면 없이 앱을 켜면 **바로 카메라 화면** (기본 카메라와 동일)

## 2. 세 버튼 한눈에 보기

| 버튼 | 한 번 누르기 (탭) | 꾹 누르기 (약 0.5초, 햅틱) |
| --- | --- | --- |
| 초기화 | 선택된 레이어 모두 해제 + 열린 패널 닫기 | **설정 화면** 열기 |
| 포즈 | 포즈 패널(목록 + 투명도 조절 바) 열기/닫기 | 아무 동작 없음 |
| MY | MY 패널(목록 + 투명도 조절 바) 열기/닫기 | **사진 추가** (사진 고르기 화면 열기) |

포즈와 MY는 같은 모양의 패널을 쓴다. 차이는 MY만 사용자가 목록에 사진을 직접 추가할 수 있다는 점이다.

## 3. 패널 (포즈 · MY 공통)

패널 = **가로 목록 한 줄 + 그 아래 투명도 조절 바**. 상단 바 바로 아래, 미리보기 위에 겹쳐서 나타난다.

- 버튼을 한 번 누르면 패널이 열리고, 같은 버튼을 다시 누르면 닫힌다. 닫아도 선택한 레이어는 화면에 남는다
- 포즈 패널과 MY 패널은 **같은 자리에 한 번에 하나만** 보인다. 포즈 패널이 열린 상태에서 MY를 누르면 포즈 패널이 닫히고 MY 패널이 열린다 (반대도 같음)
- 패널은 표시만 바뀔 뿐, 레이어 자체(포즈 테두리, MY 사진)는 둘 다 계속 겹쳐 보인다

**목록**
- 칸은 왼쪽부터 채워지는 **왼쪽 정렬**, 좌우로 밀어서 스크롤
- 칸 누름 → 선택, 그 레이어가 화면에 겹쳐짐. 선택된 칸은 노란 테두리
- 같은 목록의 다른 칸 누름 → 그걸로 교체 (각 목록에서 1개만 선택)
- 선택된 칸을 한 번 더 누름 → 선택 해제, 레이어 사라짐
- 포즈 목록과 MY 목록의 선택은 서로 독립 (포즈 1개 + MY 1개 동시 선택 가능)
- 선택 해제 방법은 두 가지뿐: ① 선택된 칸을 다시 누르기 ② 초기화 버튼 탭
- 목록 칸을 꾹 누르면 **아무 동작 없음** (포즈·MY 모두). 목록 편집은 설정 화면에서만

**투명도 조절 바**
- 그 패널에서 선택된 레이어의 투명도를 조절. 범위 5%~100%, 5% 단위 스냅, 현재 값 숫자 표시
- 선택된 레이어가 없으면 조절 바는 흐리게 표시되고 움직이지 않음
- 기본값: 포즈 테두리 **100%**, MY 사진 **35%**. 칸을 새로 선택할 때마다 기본값에서 시작 (임시 기본값, CLAUDE.md 6절)

**레이어 배치** (화면에 겹쳐진 레이어)
- 레이어는 손으로 조작하지 않음 (크기 조절·이동 없음). 항상 같은 자리에 고정
- 레이어가 켜져 있어도 화면 탭·밀기는 기본 카메라와 똑같이 동작 (탭 → 초점·노출, 좌우 밀기 → 사진/비디오 전환)
- 기본 배치: 포즈 테두리는 촬영 범위에 aspect-fit, MY 사진은 aspect-fill, 둘 다 가운데 정렬

## 4. 포즈 버튼

- **탭**: 포즈 패널 열기/닫기 (3절)
- **꾹 누르기**: 아무 동작 없음 (햅틱도 없음)
- 목록 칸에는 그 포즈를 실제로 찍은 **대표 사진**이 보이고, 선택하면 짝지어진 **포즈 테두리 PNG**가 겹쳐짐
- 포즈 데이터: 앱 번들의 `Poses/` 폴더에 `pose_XX_이름_photo.jpg` + `pose_XX_이름_line.png` 쌍 (`docs/04_ASSETS.md`). 번호 순서대로 왼쪽부터 표시
- 포즈 목록은 앱에 넣어 둔 것만 보이고, 사용자가 추가·삭제할 수 없음. 순서만 설정 화면에서 바꿀 수 있음
- 목록 칸을 꾹 눌러도 아무 동작 없음

## 5. MY 버튼

- **탭**: MY 패널 열기/닫기 (3절). 목록에는 그동안 추가한 사진들이 보임
- **꾹 누르기**: 사진 추가
  1. 아이폰 사진 고르기 화면(시스템 사진 피커)이 아래에서 올라옴. 여러 장 선택 가능, 선택 순서대로 번호 표시
  2. 오른쪽 위 **추가** 버튼 누름
  3. 고른 사진들이 MY 목록 **맨 왼쪽**에 추가됨 (여러 장이면 선택 순서대로, 1번이 맨 왼쪽)
  4. 1번 사진이 **바로 선택·적용**되어 투명도 35%로 겹쳐짐 + MY 패널이 열린 상태가 됨
  5. 취소하면 아무것도 바뀌지 않음
- 같은 사진을 다시 추가하면 중복으로 쌓지 않고 기존 칸을 맨 왼쪽으로 옮김
- 목록 편집(순서 바꾸기, 삭제, 추가)은 **설정 화면**에서 한다 (6절). 카메라 화면의 목록 칸은 꾹 눌러도 아무 동작 없음
- 저장: 추가한 사진은 앱 Documents 폴더에 복사해 두고 목록 순서와 함께 저장. 앱을 다시 켜도 MY 목록이 그대로 남음 (원본 사진을 사진 앱에서 지워도 남음)
- 목록이 비어 있을 때 MY를 탭하면, 패널에 "MY를 꾹 눌러 사진을 추가하세요" 안내 한 줄 표시

## 6. 초기화 버튼과 설정 화면

- **탭**: 포즈 선택 해제 + MY 선택 해제 + 열린 패널 닫기. 목록 자체(추가한 MY 사진들)는 지우지 않음. 확인 창 없이 바로 실행 (가벼운 햅틱)
- **꾹 누르기**: **설정 화면** 열기

### 설정 화면

디자인은 아이폰 설정 앱의 카메라 설정 화면과 같은 스타일 (`docs/reference/settings_style.png`): 회색 배경 위 둥근 흰 카드 목록(inset grouped), 섹션 제목은 회색 작은 글씨, 카드 아래 회색 설명 글, 스위치는 초록. 아이폰이 다크 모드면 시스템 다크 스타일. 아래에서 올라오는 전체 화면 시트, 왼쪽 위 뒤로/닫기, 가운데 제목 "설정".

| 섹션 | 항목 | 형태 | 내용 |
| --- | --- | --- | --- |
| 앱 아이콘 | 앱 아이콘 | 현재 아이콘 + 수정 버튼 | 홈 화면 아이콘 바꾸기 (기본 1개 + 추가 10개). 설정 화면 **맨 위** |
| 화면 표시 | 3x3 격자 | 스위치 | 카메라 화면 격자 켜기/끄기 (기본 켬) |
| 화면 표시 | 중심점 | 스위치 | 화면 정가운데 작은 십자(+) 켜기/끄기 (기본 끔) |
| 목록 | 포즈 목록 | 다음 화면 › | 포즈 순서 바꾸기만 가능 (끌어서 정렬). 추가·삭제 없음 |
| 목록 | MY 목록 | 다음 화면 › | 순서 바꾸기 + 삭제 + 추가 |
| 목록 | 카메라 목록 | 다음 화면 › | 카메라 순서 바꾸기 (7-1절). 추가·삭제 없음 |
| 정보 | 버전 | 값 | 앱 버전 |

**앱 아이콘 (설정 화면 맨 위 카드)**
- 평소: 지금 쓰는 아이콘 미리보기(둥근 아이콘 모양, 약 60pt) + 아이콘 이름 + 오른쪽 **수정** 버튼
- **수정** 탭 → 카드가 펼쳐지며 아이콘 목록이 **가로 한 줄**로 나타남 (왼쪽부터 기본, 추가 1~10, 좌우 스크롤). 지금 쓰는 아이콘에 체크 표시
- 목록에서 아이콘 탭 → 선택 표시만 바뀜 (아직 적용 안 됨)
- **확인** 탭 → 홈 화면 아이콘이 바뀌고 카드가 다시 접힘. 아이폰이 "'포징'의 아이콘을 변경했습니다" 알림을 한 번 띄움 (iOS가 띄우는 것이라 없앨 수 없음)
- **취소** 탭 → 아무것도 바뀌지 않고 접힘. 지금 아이콘과 같은 걸 골랐으면 확인 버튼은 흐리게(누를 수 없음)
- 아이콘 목록은 서윤이 넣은 것만 (사용자가 사진으로 아이콘을 만드는 건 iOS가 막아 둠)

**포즈 목록 화면**: 대표 사진 썸네일 + 번호가 한 줄씩. 오른쪽 위 "편집" → 오른쪽 끌기 손잡이로 순서 변경. 바꾼 순서가 카메라 화면 포즈 목록에 그대로 반영 (왼쪽부터).

**MY 목록 화면**: 사진 썸네일이 한 줄씩. 맨 위 "사진 추가" 줄 (누르면 시스템 사진 피커, 카메라 화면에서 MY 꾹 누르기와 같은 동작, 추가된 사진은 맨 위 = 카메라 목록 맨 왼쪽). 오른쪽 위 "편집" → 끌어서 순서 변경, 왼쪽으로 밀거나 빨간 − 버튼으로 삭제. 선택 중인 사진을 지우면 화면의 MY 레이어도 사라짐.

**카메라 목록 화면**: 카메라 PNG 썸네일 + 이름이 한 줄씩. 오른쪽 위 "편집" → 끌어서 순서 변경. 바꾼 순서가 카메라 화면 세로 목록 순서가 됨 (1번이 맨 아래). 추가·삭제 없음 (카메라는 서윤이 앱에 넣은 것만).

모든 설정은 앱에 저장되어 다시 켜도 유지.

## 7. 카메라 기본 기능

| 기능 | 동작 |
| --- | --- |
| 초점·노출 | 화면 탭 → 노란 사각형 + 오른쪽 해 아이콘. 해 아이콘 쪽을 위아래로 밀면 밝기 조절 |
| AE/AF 잠금 | 길게 누르기 → 상단에 노란 "AE/AF 잠금" 표시 |
| 격자 | 3x3 얇은 흰 선. **설정 화면**에서 켜고 끔 |
| 중심점 | 화면 정가운데 작은 십자. **설정 화면**에서 켜고 끔 |
| 수평계 | 폰이 거의 수평일 때 가운데 가로선 (기본 카메라와 동일) |
| 배율 버튼 | `.5 · 1 · 2 · 5`. 현재 버튼은 어두운 원 + 노란 글씨 + `×` (예: `1×`, `7×`) |
| 배율 다이얼 | 배율 버튼 길게 누르기 또는 좌우로 밀기 → 0.5×~25× 다이얼. 두 손가락 벌리기로도 확대 |
| 전면 카메라 | 전환 버튼. 미리보기 거울 반전, 화면 플래시, 화각 버튼. 배율 다이얼 없음 |
| 접사 | 피사체가 가까우면 왼쪽 아래 꽃 버튼 표시. 누르면 자동 접사 전환 켜기/끄기 |
| 카메라 컨트롤 버튼 | 누르면 촬영, 밀면 배율 (AVCam에 이미 있음) |
| 음량 버튼 | 누르면 촬영 |
| 썸네일 | 왼쪽 아래 원형 썸네일. 누르면 **아이폰 기본 사진 앱** 열기 (`photos-redirect://`). 앱 자체 갤러리 없음 |
| 형식 버튼 | 사진 모드 왼쪽 위 `JPEG 24` 모양 버튼 → HEIF/JPEG, 12/24/48MP 전환 (기기가 지원하는 값만) |

## 7-1. 카메라 버튼 (카메라별 색감)

셔터 **왼쪽**에 카메라 버튼을 둔다. 실제 카메라 기종(예: IXUS 750)의 사진 느낌을 고르는 기능이다.

- 버튼 모양 = **지금 선택된 카메라의 PNG 이미지** 그대로 (글자·아이콘 없음). 아무것도 고르지 않았으면 **기본** 카메라가 선택된 상태
- **탭** → 버튼 위로 카메라 목록이 **세로로** 펼쳐짐. 화면 **왼쪽**, **아래 정렬** (목록 1번이 버튼 바로 위, 2번이 그 위 …)
- 목록 칸 = 각 카메라 PNG. 선택된 칸은 노란 테두리
- 목록에서 카메라 탭 → 그 카메라로 바뀌고 목록이 닫힘. 버튼 이미지도 그 카메라 PNG로 바뀜
- 카메라 버튼 다시 탭 또는 목록 바깥 탭 → 목록 닫힘
- 꾹 누르기: 버튼·목록 칸 모두 아무 동작 없음
- 선택한 카메라는 앱을 다시 켜도 유지
- 카메라 목록 순서는 설정 화면 > 카메라 목록에서 바꿈 (6절)

**카메라마다 고유 색감**
- 카메라를 고르면 그 카메라의 색감이 미리보기와 사진에 적용됨
- **기본** = 보정 없음 (원본 그대로)
- 처음에는 **기본, IXUS 750** 두 개만. IXUS 750의 색감은 서윤이 따로 정해줄 예정 (그 전까지는 보정 없음으로 두고 자리만 만든다)
- 스타일(8절)과 같이 쓰면 카메라 색감을 먼저, 그다음 스타일을 적용 (임시 기본값)
- 사진에만 적용, 비디오 계열에는 적용 안 함. 기본이 아닌 카메라일 때 LIVE 자동 끔 (임시 기본값)
- 카메라 데이터: 앱 번들 `Cameras/` 폴더 (`docs/04_ASSETS.md`)

## 8. 더보기(•••) 메뉴

상단 오른쪽 `•••` 누르면 화면 아래에서 둥근 판이 올라오고 원형 버튼이 3열로 배치된다.

| 버튼 | 누르면 |
| --- | --- |
| 플래시 | 자동 → 켬 → 끔 |
| LIVE | 켬 ↔ 끔 (기본 카메라의 "자동"은 불가) |
| 타이머 | 끔 → 3초 → 5초 → 10초 |
| 노출 | ±2 가로 눈금 바가 나타나 전체 밝기 고정 조절 |
| 스타일 | **스타일 화면** 열기 (아래). 기본 카메라의 사진 스타일과 같은 화면·조작 |
| 비율 | 4:3 → 16:9 → 1:1 → 4:3 반복 |

기본 카메라의 야간 모드 버튼은 만들 수 없으므로 빼고, 6개 버튼(3열 2줄)만 둔다. 상단 오른쪽 묶음에는 `플래시 · LIVE · •••`만 둔다.

### 스타일 화면

기본 카메라의 "사진 스타일" 화면과 같은 모양과 조작으로 만든다. 참고 화면: `docs/reference/style_01_standard.png` ~ `style_06_stark_bw.png`.
애플의 사진 스타일 기능 자체는 다른 앱이 쓸 수 없으므로, **우리 앱이 직접 색을 보정**해서 비슷한 결과를 낸다. 애플과 완전히 같은 색은 아니고, 참고 화면과 나란히 놓고 최대한 가깝게 맞춘다.

**화면 구성 (위 → 아래)**
- 맨 위 값 표시 캡슐: `톤 40   색상 -10   팔레트 80` (표준은 `톤 · 색상`만)
- 미리보기: 둥근 모서리 카드로 줄어들고, 양옆에 이전·다음 스타일 카드가 살짝 보임. 카드를 **좌우로 밀어 스타일 변경**
- 카드 위쪽 가운데 분류 이름 캡슐 (`색조` 또는 `무드`)
- 카드 아래쪽 스타일 이름 캡슐 (예: `뉴트럴`) + 그 아래 페이지 점 (현재 위치 강조)
- 셔터: 스타일 화면에서도 그대로 촬영 가능
- 아래: **조절 패드** (점 격자 정사각형). 손가락으로 점을 끌면 가로 = 색상, 세로 = 톤. 패드 배경은 스타일 색 느낌으로 은은하게 물듦
- 패드 아래 **팔레트 슬라이더** (0~100, 표준은 없음)
- 왼쪽 아래 X 버튼: 스타일 화면 닫기 (선택한 스타일과 값은 유지)
- 포즈·MY 레이어는 스타일 화면에서도 그대로 보임

**스타일 목록 (기본 순서)**

| 순서 | 이름 | 분류 | 기본 톤 | 기본 색상 | 기본 팔레트 | 느낌 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 표준 | 색조 | 0 | 0 | 없음 | 보정 없음 (원본) |
| 2 | 뉴트럴 | 색조 | 40 | -10 | 80 | 따뜻한 기운을 빼고 담백하게 |
| 3 | 드라마틱 | 무드 | -76 | 19 | 100 | 진한 그림자, 대비 강하게, 차가운 그림자 |
| 4 | 우아하게 | 무드 | 68 | -15 | 100 | 밝고 부드럽게, 채도 낮고 살짝 차분한 색 |
| 5 | 부드러운 흑백 대비 | 무드 | 40 | 0 | 50 | 흑백, 대비 약하게 |
| 6 | 강렬한 흑백 대비 | 무드 | -100 | 0 | 50 | 흑백, 대비 강하게 |

- 값 범위: 톤 -100~100, 색상 -100~100, 팔레트 0~100
- 순서는 위 표 순서로 고정. 앱 시작 시 마지막으로 쓴 스타일과 값 유지
- 스타일마다 사용자가 바꾼 값을 따로 기억. 패드를 두 번 탭하면 그 스타일 기본값으로 되돌림
- 표준이 아닐 때는 상단 ••• 버튼 옆 등 기본 카메라와 같은 자리에 스타일 사용 중 표시 (참고 화면 기준으로 맞춤)

**적용 범위**
- 미리보기와 **사진**에 적용. 저장되는 사진에 보정이 들어가 있음 (사진 앱에서 나중에 스타일을 바꾸는 기능은 애플 전용이라 불가)
- 비디오·슬로 모션·타임랩스에는 적용하지 않음 (기본 카메라도 사진 전용)
- 표준이 아닌 스타일을 쓸 때 LIVE는 자동으로 끔 (영상 부분에는 보정을 넣을 수 없어서) — 임시 기본값, CLAUDE.md 6절

## 9. 비율

- 기본 4:3. 마지막 비율은 다음 실행에도 유지
- 미리보기 화면이 고른 비율 모양으로 바뀌고, 저장되는 사진도 정확히 그 비율 (4:3 원본을 가운데 기준으로 잘라 저장, EXIF 유지)
- 포즈·MY 레이어는 바뀐 촬영 범위 안에 다시 맞춰 배치
- 비디오 계열 모드에서는 16:9 고정, 비율 버튼 숨김

## 10. 촬영 모드 줄

셔터 아래 모드 이름 줄을 좌우로 밀어 바꾼다. 선택된 모드는 가운데 둥근 판 안에 노란 글씨. 양 끝은 흐려짐.

순서: **타임랩스 · 슬로 모션 · 비디오 · 사진** (앱 시작 시 사진)

| 모드 | 내용 |
| --- | --- |
| 사진 | 이 문서의 모든 사진 기능 |
| 비디오 | 4K/HD, 24/30/60fps. 왼쪽 위 `HD 해상도 · 30 FPS` 버튼 누르면 각각 바뀜. 손떨림 보정, 마이크 녹음. 녹화 중 상단 빨간 시간 |
| 슬로 모션 | 120/240fps 고속 촬영, 느린 영상으로 저장 |
| 타임랩스 | 일정 간격으로 장면을 모아 영상으로 저장 |

셔터: 사진은 흰 원, 비디오 계열은 빨간 원 (기본 카메라와 동일). 모든 모드에서 포즈·MY 레이어 사용 가능.

## 11. 사진·영상 품질

- `photoQualityPrioritization = .quality`, Zero Shutter Lag / Responsive Capture (AVCam 설정 유지)
- 저장: 셔터를 누르면 확인 창 없이 **아이폰 기본 사진 앱(최근 항목)**에 바로 저장 (PHPhotoLibrary). 라이브 포토는 사진 + 짧은 영상을 함께 저장
- 앱 안에 따로 보관하지 않음. 왼쪽 아래 썸네일도 기본 사진 앱을 염
- 처음 촬영할 때 "사진에 추가" 권한을 한 번 물어봄 (추가 전용). 거절하면 "설정에서 사진 추가를 허용해주세요" 안내와 설정 앱 열기 버튼

## 12. 만들지 않는 것
