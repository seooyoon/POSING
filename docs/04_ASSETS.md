# 04 에셋 규격 (서윤이 만들어서 넣는 것)

## 1. 포즈 세트 (필수)

포즈 하나 = **대표 사진 1장 + 테두리 PNG 1장**. 같은 번호·이름으로 짝을 맞춘다.

| 파일 | 규격 | 쓰임 |
| --- | --- | --- |
| `pose_01_브이_photo.jpg` | 정사각형 600 × 600px, JPG 또는 PNG | 포즈 목록에 보이는 대표 사진 |
| `pose_01_브이_line.png` | 1536 × 2048px (3:4 세로), **투명 배경** PNG | 카메라 화면에 겹치는 테두리 |

- 넣는 위치: 프로젝트의 `Posing/Resources/Poses/` 폴더 (Xcode에서 **폴더 참조(파란 폴더)**로 추가 → 파일만 넣으면 자동 인식)
- 번호(`01`, `02` …) 순서대로 목록에 표시. 이름 부분은 목록에 표시하지 않음 (파일 구분용)
- 테두리 선: 흰색 6~8px + 바깥쪽에 얇은 어두운 그림자/테두리 → 밝은 하늘·어두운 실내 모두에서 보임
- 테두리는 실제로 찍힐 위치·크기에 맞춰 그리기 (3:4 촬영 화면 기준). 앱에서 조절은 가능
- 대표 사진은 테두리와 같은 포즈를 실제로 찍은 사진
- 추천 구성: 전신, 상반신, 앉은 자세, 뒷모습, 2인 등 구도별로

## 2. 앱 아이콘 (필수)

- **디자인 확정** (`docs/reference/app_icon_preview.png`): 볼을 감싼 캐릭터 얼굴 + 하단 흰 글자 "POSING", 왼쪽 위 ⌜ 표시, 오른쪽 위 빨간 점, 연한 베이지 배경
- 지금 받은 파일은 426 × 426px 미리보기. **1024 × 1024px 원본으로 다시 받아서** 넣는다 (작은 파일을 키우면 흐려짐)
- 규격: 1024 × 1024px PNG, 모서리 각지게 (둥근 모서리는 iOS가 자동 처리). 둥근 모서리로 깎아 봤을 때 잘리는 요소 없음
- 넣을 때 투명도 정보(알파 채널)를 빼고 RGB로 저장 (앱스토어 규격. 받은 파일은 RGBA라 변환 필요)
- 넣는 위치: `Assets.xcassets/AppIcon` (Xcode의 1024 단일 크기 아이콘)

### 추가 앱 아이콘 (설정에서 바꾸기용, 10개)
- 기본 아이콘과 같은 규격: 1024 × 1024px PNG, 모서리 각지게, 투명도 없음
- 파일 이름: `icon_01_이름.png` ~ `icon_10_이름.png` (번호 = 목록 순서, 이름 = 설정에 보이는 이름)
- 넣는 위치: `Assets.xcassets`에 아이콘 세트로 하나씩 (`AppIcon-01` …). Claude Code에 파일을 주고 "추가 아이콘으로 넣어줘"라고 하면 됨
- 기본 아이콘 이름은 "기본"
- 10개가 다 없어도 됨. 넣은 개수만큼 목록에 보임
- 선택: iOS 18 다크·색조 아이콘 변형 (같은 크기)

## 3. 앱 이름 (필수)

- 확정: **포징** (영문 POSING). 홈 화면 표시 이름은 "포징"
- Claude Code에 "앱 표시 이름을 ○○로 바꿔줘"라고 요청

## 3-1. 카메라 목록 (필수)

카메라 하나 = **PNG 1장 + 색감 정보**.

| 파일 | 규격 | 쓰임 |
| --- | --- | --- |
| `camera_01_기본.png` | 512 × 512px, **투명 배경** PNG | 카메라 버튼·목록에 그대로 보이는 이미지 |
| `camera_02_IXUS750.png` | 512 × 512px, 투명 배경 PNG | 〃 |
| `camera_02_IXUS750.cube` (선택) | 색 보정 LUT 파일 (.cube) | IXUS 750 색감. LUT가 없으면 서윤이 알려주는 톤·색상·채도 같은 값으로 대신 구현 |

- 넣는 위치: `Posing/Resources/Cameras/` (폴더 참조)
- 번호 순서가 기본 목록 순서 (01이 맨 아래). 이름 부분이 설정 화면에 표시되는 카메라 이름
- 이미지는 52pt 정도로 작게 보이므로 윤곽이 또렷한 정면 카메라 그림이 잘 보임
- 기본 카메라는 색감 파일 없음 (보정 없음)
- 참고: 앱스토어에 올릴 때는 실제 제품 이름(IXUS 등 다른 회사 상표)을 쓰면 심사에서 문제될 수 있음. 지금처럼 내 폰에 설치해서 쓰는 건 상관없음

## 4. 기본 카메라 스크린샷 (참고용)

`docs/reference/` 폴더에 넣는다. 파일 이름은 내용을 알 수 있게:
- `photo_main.png` — 사진 모드 기본 화면
- `photo_focus.png` — 초점 사각형 + 해 아이콘
- `more_menu.png` — ••• 메뉴 연 화면
- `mode_strip_*.png` — 모드 줄을 민 화면들
- `video_main.png` — 비디오 모드
- 있으면 좋음: `zoom_dial.png`(배율 다이얼), `selfie.png`(셀카), `exposure_bar.png`(노출 바), `timer.png`

## 5. 선택

- 상단 버튼 전용 아이콘 (초기화·포즈·MY): 지금은 글자 버튼. 아이콘으로 바꾸고 싶으면 단색 SVG
- 영상용 포즈 테두리 (9:16, 1152 × 2048px): 없으면 3:4 테두리를 맞춰서 사용
