# 04 에셋 규격 (서윤이 만들어서 넣는 것)

## 1. 포즈 세트 (필수)

포즈 하나 = **대표 사진 1장 + 테두리 PNG 1장**. 같은 번호·이름으로 짝을 맞춘다.

| 파일 | 규격 | 쓰임 |
| --- | --- | --- |
| `pose_01_브이_photo.jpg` | 정사각형 600 × 600px, JPG 또는 PNG | 포즈 목록에 보이는 대표 사진 |
| `pose_01_브이_line.png` | 1536 × 2048px (3:4 세로), **투명 배경** PNG | 카메라 화면에 겹치는 테두리 |

- 넣는 위치: 프로젝트의 `Posing/Resources/Poses/` 폴더 (Xcode에서 **폴더 참조(파란 폴더)**로 추가 → 파일만 넣으면 자동 인식)
- 번호(`01`, `02` …) 순서대로 목록에 표시. 이름 부분은 목록에 표시하지 않음 (파일 구분용)
- 테두리 선: 흰색 6~8px + 바깥쪽에 얇은 어두운 그림자/테두리 → 밝은 하늘·어두운 실내 모두에서 보임
- 테두리는 실제로 찍힐 위치·크기에 맞춰 그리기 (3:4 촬영 화면 기준). 앱에서 조절은 가능
- 대표 사진은 테두리와 같은 포즈를 실제로 찍은 사진
- 추천 구성: 전신, 상반신, 앉은 자세, 뒷모습, 2인 등 구도별로

## 1-1. MY 패키지 (여행용)

패키지 하나 = **폴더 하나** (`대표 이미지 + 사진들`). MY 패널에서 패키지 목록 → 패키지 안 사진들로 보인다 (`docs/01_SPEC.md` 5절).

| 파일 | 규격 | 쓰임 |
| --- | --- | --- |
| `MYPackages/01_서윤 사진/cover.jpg` | 정사각형 추천 (600 × 600px 정도), JPG 또는 PNG | 패키지 목록 · 패키지 안 맨 왼쪽의 대표 이미지. 없으면 첫 사진 |
| `MYPackages/01_서윤 사진/01.jpg`, `02.jpg` … | 아무 비율, 긴 변 2400px 이하 추천 | 화면에 35%로 겹칠 사진 |

- 넣는 위치: `Resources/MYPackages/` (폴더 참조). 폴더 이름 `번호_패키지 이름` → 번호순으로 목록에, 이름 부분이 패키지 이름
- 사진은 파일 이름 번호순으로 나열되고 사용자가 순서를 바꿀 수 없음
- 지금은 확인용 `01_예시`(샘플 포즈 사진 3장)만 있음. 서윤 · 동생 패키지를 받으면 바꿔 넣음
- Claude Code에 패키지 이름과 사진들을 주고 "MY 패키지로 넣어줘"라고 하면 됨

## 2. 앱 아이콘 (필수)

- **디자인 확정** (`docs/reference/app_icon_preview.png`): 볼을 감싼 캐릭터 얼굴 + 하단 흰 글자 "POSING", 왼쪽 위 ⌜ 표시, 오른쪽 위 빨간 점, 연한 베이지 배경
- 1024 × 1024px 원본을 받아 넣음 (`AppIcon.appiconset/AppIcon.png`)
- 규격: 1024 × 1024px PNG, 모서리 각지게 (둥근 모서리는 iOS가 자동 처리). 둥근 모서리로 깎아 봤을 때 잘리는 요소 없음
- 넣을 때 투명도 정보(알파 채널)를 빼고 RGB로 저장 (앱스토어 규격. 받은 파일은 RGBA라 변환 필요)
- 넣는 위치: `Assets.xcassets/AppIcon` (Xcode의 1024 단일 크기 아이콘)

### 추가 앱 아이콘 (설정에서 바꾸기용, 12개)
- 기본 아이콘과 같은 규격: 1024 × 1024px PNG, 모서리 각지게, 투명도 없음
- 파일 이름: `icon_01_이름.png` ~ `icon_12_이름.png` (번호 = 아이콘 세트 번호, 이름 = 설정에 보이는 이름). 설정에 보이는 순서는 번호와 따로 `AppIconOption.all`에서 정함
- 넣는 위치: `Assets.xcassets`에 아이콘 세트로 하나씩 (`AppIcon-01` …). Claude Code에 파일을 주고 "추가 아이콘으로 넣어줘"라고 하면 됨
- 기본 아이콘 이름은 "기본"
- 넣은 12개: `AppIcon-01` 사람 · `02` 강아지 · `03` 고양이 · `04` 구름 · `05` 닭 · `06` 병아리 · `07` 쥐 · `08` 돼지 · `09` 원숭이 · `10` 토끼 · `11` 파랑 로고 · `12` 검정 로고. 목록 미리보기는 `IconPreview-00`(기본) ~ `12` (180px). 설정에 보이는 이름 · 순서는 `SettingsView.swift`의 `AppIconOption.all` (기본, 사람, 파랑 로고, 검정 로고, 토끼, 강아지, 고양이, 닭, 병아리, 쥐, 돼지, 원숭이, 구름)
- 아이콘을 더하거나 빼면 `AppIconOption.all` 이름 목록도 같이 고침
- 선택: iOS 18 다크·색조 아이콘 변형 (같은 크기)

## 3. 앱 이름 (필수)

- 확정: **포징** (영문 POSING). 홈 화면 표시 이름은 "포징"
- Claude Code에 "앱 표시 이름을 ○○로 바꿔줘"라고 요청

## 3-1. 카메라 목록 (필수)

카메라 하나 = **PNG 1장 + 색감 정보**.

| 파일 | 규격 | 쓰임 |
| --- | --- | --- |
| `camera_01_기본.png` | 512 × 512px, **투명 배경** PNG | 카메라 버튼·목록에 그대로 보이는 이미지 |
| `camera_02_POSING.png` | 512 × 512px, 투명 배경 PNG | 〃 (흰색 · 베이지 카메라. 옛 이름 IXUS750) |
| `camera_02_POSING.cube` | 색 보정 3D LUT (.cube, 17×17×17) | POSING 디카 색감. 서윤이 준 비교 사진으로 계산해 넣음 (#119) |
| `camera_03_테스트1.png` | 512 × 512px, 투명 배경 PNG (민트 카메라) | 목록 확인용 임시 카메라. 여행 전에 실제 카메라로 바꾸거나 삭제 |

- 넣는 위치: `Posing/Resources/Cameras/` (폴더 참조)
- 목록 순서는 번호와 상관없이 즐겨찾기 먼저, 각각 이름순(가나다 → abc). 이름 부분이 화면에 보이는 카메라 이름
- 이미지는 52pt 정도로 작게 보이므로 윤곽이 또렷한 정면 카메라 그림이 잘 보임
- 기본 카메라는 색감 파일 없음 (보정 없음)
- 참고: 앱스토어에 올릴 때는 실제 제품 이름(IXUS 등 다른 회사 상표)을 쓰면 심사에서 문제될 수 있음. 지금처럼 내 폰에 설치해서 쓰는 건 상관없음
