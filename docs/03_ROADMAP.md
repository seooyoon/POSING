# 03 개발 단계

단계마다 Claude Code에 붙여 넣을 요청문, 완료 기준, 서윤이 실기기에서 확인할 것을 적었다.
**여행에 꼭 필요한 건 0~4단계**이고, 5단계 이후는 시간이 남으면 진행한다.

---

## 0단계 — 준비 (서윤이 직접, Xcode 화면에서)

- [ ] 애플 개발자 사이트에서 AVCam 예제 내려받기 → 압축 풀어 이 폴더(`Posing/`)에 프로젝트를 넣기
- [ ] Xcode > Settings > Accounts 에서 애플 ID 로그인
- [ ] 프로젝트 > Signing & Capabilities: Team = 내 Personal Team, Bundle Identifier = `com.seoyun.posing`
  - AVCam의 잠금화면 확장(extension) 타깃이 있으면 같은 Team으로 맞추거나, 서명 오류가 나면 Claude Code에 "확장 타깃 제거"를 요청
- [ ] 아이폰 연결 → 설정 > 개인정보 보호 및 보안 > 개발자 모드 켜기
- [ ] Xcode에서 실행(▶) → 아이폰 설정 > 일반 > VPN 및 기기 관리 > 내 개발자 앱 신뢰
- [ ] AVCam이 폰에서 사진을 찍는지 확인
- [ ] 이 폴더에서 `git init` 후 첫 커밋
- [ ] 기본 카메라 스크린샷을 `docs/reference/`에 넣기

> 여기까지 되면 개발 환경 준비 끝. 이후는 Claude Code가 코드를 고치고, 서윤은 Xcode에서 ▶ 눌러 폰에 설치해 확인한다.

---

## 1단계 — 기본 카메라 화면 뼈대

**요청문**
```
CLAUDE.md와 docs/01_SPEC.md, docs/02_UI.md를 읽고 1단계를 진행해줘.
AVCam 프로젝트 구조를 먼저 파악해서 요약해주고, 카메라 처리 코드는 살린 채
화면을 docs/02_UI.md의 기본 카메라 배치로 바꿔줘.
- 상단 바: 형식 버튼, 초기화·포즈·MY 개별 버튼 3개(따로 떨어진 둥근 버튼, 아직 동작 없음), 플래시·LIVE·••• 캡슐
- 하단: 셔터, 원형 썸네일(탭하면 기본 사진 앱), 비디오|사진 캡슐, 전환 버튼
- 시뮬레이터용 가짜 카메라(샘플 이미지)
- AppDefaults.swift에 CLAUDE.md 6절 임시 기본값 정리
```
**완료 기준**: 시뮬레이터에서 배치가 스크린샷과 비슷하게 보이고, 실기기에서 사진 촬영·저장이 그대로 된다.
**실기기 확인**: 사진 찍기, 썸네일 눌러 사진 앱 열리는지, 비디오 녹화.

---

## 2단계 — 포즈 · MY · 초기화 (핵심)

**요청문**
```
docs/01_SPEC.md 1~6절과 docs/02_UI.md 2~4절대로 포즈 · MY · 초기화 버튼을 구현해줘.
- 세 버튼의 탭 / 꾹 누르기 동작 (포즈는 꾹 눌러도 반응 없음)
- 포즈 · MY 패널: 왼쪽 정렬 가로 목록 + 투명도 조절 바(5~100%), 같은 자리에 한 번에 하나만
- 포즈 목록은 번들의 Poses/ 폴더에서 _photo/_line 쌍을 읽어서 표시 (docs/04_ASSETS.md)
- MY 꾹 누르기 → 시스템 사진 피커(여러 장) → 목록 맨 왼쪽에 추가 + 1번 바로 적용(35%), 목록은 앱에 저장해서 다시 켜도 유지
- 포즈 1개 + MY 1개, 최대 2개 동시 선택. 포즈 테두리가 항상 위
- 초기화 꾹 누르기 → 설정 화면 (docs/01_SPEC.md 6절, docs/02_UI.md 4절): 포즈 목록 정렬, MY 목록 정렬·삭제·추가, 카메라 목록 정렬, 격자·중심점 스위치는 저장만 하고 3단계에서 화면에 연결
- 카메라 화면 목록 칸은 꾹 눌러도 아무 동작 없게
- 레이어는 고정 (손 조작 없음), 화면 탭·밀기는 기본 카메라와 같게
- 레이어는 SwiftUI 뷰로만. 저장 경로에 레이어가 섞이지 않는지 코드로 다시 확인해서 알려줘
- 테스트용 임시 포즈 3개(단순 도형 PNG)를 만들어 넣어줘
```
**완료 기준**: 포즈·MY 선택/해제/교체/투명도 조절, MY 사진 추가·삭제·앱 재시작 후 유지, 초기화 탭/꾹 누르기가 명세대로 동작.
**실기기 확인**
- [ ] 포즈 + MY를 둘 다 켜고 사진 촬영 → 사진 앱에서 레이어가 **없는지**
- [ ] 같은 상태로 비디오 녹화 → 영상에 레이어 없는지
- [ ] 비행기 모드에서 MY 꾹 눌러 사진 추가
- [ ] 앱을 완전히 껐다 켜도 MY 목록이 남아 있는지
- [ ] 설정에서 포즈·MY 순서를 바꾸면 카메라 화면 목록에 그대로 반영되는지
- [ ] 포즈를 나중에 골라도, MY를 나중에 골라도 포즈 테두리가 항상 위에 있는지

## 3단계 — 카메라 조작

**요청문**
```
docs/01_SPEC.md 7절과 docs/05_TECH_NOTES.md를 보고 카메라 조작을 구현해줘.
탭 초점·노출 + 해 아이콘 밝기, 길게 눌러 AE/AF 잠금, 3x3 격자와 중심점(설정 스위치와 연결), 수평계,
배율 버튼(.5/1/2/5)과 다이얼(0.5×~25×), 두 손가락 확대, 전면 카메라(거울·화각·화면 플래시),
접사 꽃 버튼. 배율은 builtInTripleCamera 기준으로 표시 배율을 변환해줘.
```
**완료 기준**: 기본 카메라와 나란히 놓고 같은 장면에서 조작이 비슷하게 동작.
**실기기 확인**: 0.5×·1×·2×·5×·25× 각각 촬영, 가까운 물체에서 꽃 버튼, 셀카.

---

## 4단계 — 더보기 메뉴 · 비율 · 형식

**요청문**
```
docs/01_SPEC.md 8~9절, docs/02_UI.md 8절대로 더보기(•••) 메뉴를 구현해줘.
플래시, LIVE, 타이머, 노출, 스타일(버튼 자리만, 기능은 6단계), 비율(4:3→16:9→1:1). 야간 모드 자리는 빼고 6개 버튼만.
비율 변경 시 미리보기 모양, 저장본 자르기(EXIF 유지), 레이어 재배치까지.
왼쪽 위 형식 버튼(HEIF/JPEG, 해상도)도.
```
**완료 기준**: 메뉴 모양과 버튼별 동작이 기본 카메라와 같고, 비율별 저장 사진이 정확한 비율.
**실기기 확인**: 비율 3가지로 각각 찍어 사진 앱에서 비율 확인, 타이머 촬영.

> **여기까지 되면 여행에서 쓸 수 있는 버전.** 출발 1~2일 전에 설치한다.

## 5-1단계 — 카메라 버튼 (카메라별 색감)

**요청문**
```
docs/01_SPEC.md 7-1절, docs/02_UI.md 7절, docs/04_ASSETS.md 3-1절대로 셔터 왼쪽 카메라 버튼을 만들어줘.
- 버튼 = 선택된 카메라 PNG, 탭하면 왼쪽에 세로 목록(아래 정렬, 1번이 맨 아래)
- Cameras/ 폴더에서 카메라를 읽고, 기본과 IXUS 750 두 개로 시작
- 색감은 카메라마다 따로 적용할 수 있는 구조로 (기본 = 보정 없음, IXUS 750은 일단 보정 없음으로 자리만)
- 설정 화면 카메라 목록에서 순서 바꾸기 연결
- 색감 보정은 스타일(6단계)과 같은 필터 경로를 쓰게 설계해줘
```
**실기기 확인**: 카메라 바꾸면 버튼 이미지가 바뀌는지, 앱 다시 켜도 선택 유지되는지.

## 6단계 — 스타일 · LIVE 마무리 · 카메라 컨트롤

**요청문**
```
docs/01_SPEC.md 8절 "스타일 화면", docs/02_UI.md 8-1절, docs/05_TECH_NOTES.md 4절대로 스타일 기능을 만들어줘.
- 스타일 6개(표준~강렬한 흑백 대비), 좌우로 넘기기, 톤·색상 패드, 팔레트 슬라이더, X 닫기
- docs/reference/style_*.png와 같은 장면을 찍어 비교하면서 색을 맞출 수 있게 StylePresets.swift에 값을 모아줘
- 스타일 순서는 고정 (설정에서 바꾸지 않음)
- 먼저 Metal 미리보기 방식과 성능 영향을 설명하고 내 확인을 받은 뒤 진행해줘
LIVE 저장, 음량 버튼 촬영, 카메라 컨트롤 버튼(촬영·배율)이 모두 되는지 점검해줘.
```
